# 官網審查第一批

日期：2026-10-22。來源：`collab/website-source` 的 `sites/kyokushin-life/`（交付修訂 `9626593`）。
依 `docs/CLAUDE-WEBSITE-HANDOFF.md`：只審查官網文案、視覺、手機排版、導覽與導流連結；不碰主遊戲、反應組手邏輯與人物美術。

## 測試方法

- `node check-site.cjs`（靜態檢查）。
- 以 `preview.cjs` 提供 `dist/`，用無頭 Chromium 在 320×568、375×667、390×844、430×932（含 130% 字級）與 1280×800 檢查：橫向溢出、首屏按鈕位置、觸控目標大小、11px 以下文字、選單開關與 ARIA、頁籤鍵盤操作、焦點樣式、圖片載入、JavaScript 錯誤。
- 線上頁面（`kyokushin-life.blushriver128.chatgpt.site`）在我的環境回 403，所以**沒有做線上驗證**；以下都是來源檔的結果。也沒有做真人理解或成效試驗。

## 沒有問題的部分

- 所有寬度都沒有橫向捲軸，沒有 JavaScript 錯誤，六張素材都載入。
- 手機首屏：標題在 163px、「開始我的極真人生」按鈕在 379～432px，第一屏就看得到；導覽圖在其下方。
- 選單：`aria-expanded` 正確切換，四個項目各 49～51px 高，Esc 可關閉並把焦點還給按鈕。
- 四條路線與三篇故事的頁籤：方向鍵、Home／End 可切換，`aria-selected` 與 `aria-labelledby` 同步更新，焦點有 3px 金色外框。
- 四個導流連結目標正確：正式遊戲、反應組手、結語示範（`preview-v2/ending-preview.html` 存在於主專案）、支部 IG。`?v=27`／`?v=21` 只是快取參數，不算失效。
- 沒有 `sensei`；女生導覽圖在首屏、故事與反應組手三處都保留。
- 「示意文字・非玩家存檔」「故事示意」「玩法示意」與非官方、虛構說明都在。
- 已有 `prefers-reduced-motion` 處理；動畫只有裝飾用途。

### W1 故事文案多餘空格（已修）
- `dist/app.js` 第 8、9 行：「前輩 沒有催」「那一聲 前輩，」。應是把舊稱呼換成「前輩」時留下的空格。`index.html` 裡首次載入的靜態文字沒有空格，所以點「02 同行」再點回「01 回望」，同一段文字會多出一個空格。
- 修法：刪掉兩個空格。驗證：切換頁籤後 `#story-copy` 內容含「前輩沒有催」。

### W2 手機版文字過小（已修）
- 760px 以下的樣式把 25 處文字設成 8～10px：頁尾說明 8px、首屏「瀏覽器直接玩」9px、路線說明 9px、結尾「第一次來…」9px、路線標籤 9px、反應組手說明 9px 等。
- 修法：手機樣式區塊內所有 8～10px 一律改 11px（裝飾用的「▪ ▪ ▪」除外）；桌機也套用的 `.book-chapter`、`.story-sign`、`.route-top`、`.route-ticket span`、`.route-tags span`、`.reaction-top`、`.reaction-demo>p` 改 11px。
- 驗證：390px 與 320px 下，掃描所有有文字的元素，沒有小於 11px 的。整頁高度 6501px → 6699px（+3%）。

### W3 觸控目標（已修）
- 「先看看怎麼玩」78×15、「向下探索」57×13、「看看結語示範」72×15、頁尾三個連結 52×15、「去選擇我的起點」高 22px。
- 修法：手機版這些連結設 `min-height:44px; display:inline-flex`，外觀不變。驗證：390px 與 320px 下沒有高度小於 40px 的連結或按鈕（品牌標誌 39px 高，寬 124px 以上，維持）。

### W4 米色區塊小字對比（已修）
- `.side-note` 2.67:1、`.route-caption` 3.17:1、章節 eyebrow 3.27:1、`.book-chapter` 2.50:1、`.story-sign` 2.33:1。
- 修法：改為 #6f6858（4.70:1）、#8c7a60（3.52:1）、#8a7756（3.68:1）、#8d5a46、#655a46。色相不變，仍是暖棕。深色底的小字本來就在 5.4:1 以上，沒動。

### W5 導覽圖大小（已修）
- `dojo-guide.webp` 1536×1024、196KB，同一張用在首屏、故事、反應組手三處；手機上最寬只顯示 339px（2× 螢幕需要 678px）。
- 修法：新增 `dojo-guide-768.webp`（768×512，53KB，由原圖縮小，品質 82）。首屏與反應組手用 `srcset` 依寬度選擇；故事區的小圓角肖像直接用 768 版。桌機首屏仍載入原圖。
- 驗證：390px 載入 768 版，1280px 首屏載入原圖。手機首屏圖片從 196KB 降到 53KB。
- `check-site.cjs` 改為計算 `<img>` 數量並檢查 `srcset` 的檔案存在。

### W6 三代傳承只畫兩代（已修）
- 手機樣式把第三個角色和箭頭藏起來，文案卻寫「延續三代傳承」。三個 25px 的角色其實放得下。
- 修法：移除那兩條隱藏規則。驗證：390px 下 `.lineage` 有 3 張可見圖片。

### W7 路線頁籤的「↗」（建議，未改）
- 四條路線的頁籤右側有「↗」，和整站「開始遊戲 ↗」的外部連結符號一樣，但點了只是切換下方預覽。可改成「›」或拿掉。屬設計偏好，等使用者決定。

### W8 og:image（待確認，未改）
- `og:image` 指向 `kyokushin-life.blushriver128.chatgpt.site/assets/icon.png`。官網仍有帳號存取限制時，社群平台抓不到這張圖，分享預覽會沒有圖片。開放存取後就沒問題；或者改指向 GitHub Pages 上的 `icon-512.png`。
