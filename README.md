# 極真人生・中村道場台灣支部篇

以極真空手道中村道場台灣支部為藍本的空手道人生模擬遊戲（非官方作品，人物與事件皆為虛構）。

[開始遊玩](https://ikontaiwan.vercel.app/?v=33) · [官網](https://ikontaiwan.vercel.app/site/) · [專案說明](PROJECT.md)

從 15 歲青春競技、15 歲終身修行、30 歲成年入門或 45 歲第一次入門開始，體驗稽古、升帶、賽事、內弟子、教學、道場與三代傳承。弟子會記得你的教學選擇，故事以回望、同行、給自己三頁呈現，另可翻閱年度回顧。手機、電腦瀏覽器都能玩。

## 存檔

正式版沿用原本的進度、成就與顯示設定。每個人生都照它開始時的規則繼續；新人生使用**規則 33**（看破、招式熟練 Lv、後天被動技能、全台少年組、年初比賽計畫）。各規則內容見 [PROJECT.md](PROJECT.md#4-規則版本存檔相容)。

測試版與正式版的進度仍分開。要轉移測試版人生：在測試版遊戲中按「📋 存檔碼」，複製後到正式版首頁按「📥 輸入存檔碼」。讀入成功會取代此瀏覽器現有的正式版人生，請先保留需要的存檔碼。示範人生仍使用獨立進度空間。
