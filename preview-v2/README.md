# 極真人生 v2.1 手機測試版

[開始遊戲](https://a58045555.github.io/ikontaiwan/preview-v2/) · [直接看結語與年度回顧展示](https://a58045555.github.io/ikontaiwan/preview-v2/ending-preview.html)

本次更新：

- 結語預設只顯示一段短結語、四個重點數字、最多三個人生時刻。
- 回憶、家人、宿敵、書信等完整故事保留，改為逐篇展開；完整紀錄與額外玩法也預設收起。
- 新增逐年回顧：腰帶、原始能力總和、存款變化、戰績、受傷次數、稽古安排、重大事件與當年的重要選擇。
- 當年尚未走完會標示「進行中」，最後一年則標示「截至結算」。回顧採年度前後差額，並非把所有變化歸因於單一選項。
- 分享卡改為 1080×1440 的精簡紀念卡。結尾不再自動跳出招生視窗。

回顧由原本的開局與選擇紀錄重新建立，保留 v19／v20 存檔相容性，不修改遊戲能力、選擇順序或亂數。一般測試版繼續使用原有 kyokushin-preview-v20 儲存空間，更新不會要求重新開局。

展示頁使用一般 v20 規則自動遊玩的虛構角色，專用儲存前綴為 kyokushin-ending-demo-v21，與一般測試版及正式版進度分開。可直接翻閱其結語與年度回顧。

驗證：在專案根目錄執行 `node validation/verify-yearbook.cjs`，包含 23 項結語、年度資料、存檔重建、失敗匯入、亂數、文字轉義與完整人生回歸檢查。另外已通過工作區原有 90 項檢查，以及展示頁存檔隔離檢查。

瀏覽器檢查包含手機尺寸、年度切換、關閉後仍停在相同選擇，以及分享圖片尺寸與排版；未涵蓋所有實機瀏覽器。

本次僅更新 preview-v2 與新增年度回顧驗證程式；根目錄正式版、beta、hanno 與既有素材不變。
