# 極真人生 v2.6 檢查與後續設計

2026-10-20。這份完成度是依功能與檢查結果作出的設計評估，不是玩家研究或市場成效數據。

## 本次已完成

- 道場語境使用 sensei。學校、家教、瑜伽老師及「老師範」保留原來意思。畫面顯示時轉換歷史事件文字，舊存檔重播所需的原始事件、亂數及選項紀錄不變。
- 回望、同行、給自己仍為最多三頁。部分段落增加情節與心聲；既有示範人生總文字量約增加三成，每段限制在 245 字元以下。弟子引言後的旁白另行換行。
- 修正尚未升黑帶的單一弟子，在敘事資料中被忽略的問題；會以目前修行狀態說話，不替他補寫黑帶或冠軍。
- 修正重開道場後，舊關館標記仍讓致詞誤稱目前道場已關閉的問題。
- 修正完成紀錄只依種子、選項數量、年齡去重，可能合併不同人生的問題。新紀錄依完整設定與選項內容產生識別碼；保留舊紀錄。既有舊格式人生第一次重讀時，可能新增一筆新版識別的紀錄，後續會去重。
- 每日挑戰的命運欄是隱藏欄位，本次補齊啟用／取消時的鎖定狀態，屬設定一致性補強。
- 加入每次修改測試版或驗證程式時自動執行的 GitHub Actions 檢查。它回報檢查狀態，沒有變更部署或分支保護規則。

## 檢查範圍

舊版相容、存檔碼壓縮與損壞處理、匯入失敗回復、機率顯示、資格條件、年度回顧、弟子上限與個別成長、結語事實、文字跳脫、隨機重讀一致，以及 120 段完整人生及重播。

新交互矩陣包含九間道場、六種志向、兩種性別的完整組合，並輪替五種量級；另含隨機選擇策略。每次選擇檢查金錢、體況與能力為有效數值，以及弟子上限。這不代表所有種子、操作時機及裝置組合已窮盡。

本機另比對未修改的既有函式與舊版完整人生快照；存檔規則維持 21。手機寬度 320／390 檢查三頁故事、sensei 顯示與每日挑戰切換。iOS Safari、不同字體與低階實機仍需真人測試。

## 完成度判斷

以可公開試玩的獨立文字養成遊戲為標準，整體約 75–80%。

| 面向 | 主觀估計 | 判斷依據 |
|---|---|---|
| 核心人生循環 | 85% | 稽古、審查、賽事、內弟子、教學、經營到退休有完整流程 |
| 故事與重玩 | 80% | 有分支與隨機文本，但人物關係仍有不少以狀態旗標概括的地方 |
| 新手體驗與平衡 | 65–70% | 有一堂課體驗與提示，仍需觀察真正第一次玩的人的選擇與卡點 |
| 維護與驗證 | 75% | 加入交互回歸與自動檢查；單一大型 HTML、全域狀態與重播相依仍增加改版成本 |
| 推廣到實際體驗課 | 50–60% | 有道場題材、情感與社群連結，尚未驗證遊玩能否帶來詢問、體驗與持續參與 |

## 下一批優先順序

1. 終身會員／成年入門路線：目前從十五歲起步，32 歲未拿指導員資格會提早結算。若目標是推廣，應讓不追逐資格、晚開始或只想規律運動的人，也能擁有完整人生與值得期待的結局。屬新規則設計，需獨立版本與存檔相容策略。
2. 讓選擇被人物記住：弟子加入時先有小目標；日後的信具體提到你曾選擇的陪伴、基本功、心態或放手。以真實事件回扣取代只增加隨機形容詞。
3. 兩至三代傳承：弟子成為助教、分館指導員或自己的弟子的 sensei，讓早年的教法留下可看見的影響。先做好少數互斥分支，避免只堆事件數。
4. 入門知識與體驗入口：用短圖卡說明禮儀、基本、型、組手，區分遊戲簡化與現場課程；從所選道場提供經核對的正式社群與體驗資訊。
5. 平衡與程式結構：觀察十位新手是否理解目標與放棄原因，再調整機率、時限及推薦；逐步分出規則、事件資料、存檔與介面模組，保留重播快照後再做拆分。

## 推廣空手道是否有用

我認為它適合做引起興趣、認識道場人情與培養持續修行想像的入口。真正的推廣效果仍須驗證。戲劇性結局能留下印象，但入門部分也應呈現友善、循序漸進及日常練習，讓沒打算當選手的人看見自己的位置。

中村道場的稽古介紹包含禮儀、基本、型、打靶與配戴護具的組手；初心者問答也介紹未經驗者與體驗課。建議以這些正式內容校對遊戲中的入門知識，不把遊戲數值、升帶年限或職涯門檻當成現實通則。
